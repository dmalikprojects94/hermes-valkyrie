# Coding Terminal Memory

This is the Folder-Start baseline for every Hermes-managed Codex runtime surface.

Keep durable operating rules in skills or memories that can be rebuilt from the loadout repo. Do not store authentication files, session databases, raw outputs, or generated terminal captures here.

Every specialized Codex loadout overlays additional skills and memories on top of this baseline.

## Provenance

- Source: internal Hermes-operator runtime-surface design.
- Disposition: runtime-specific-adapter for Codex baseline.
- Notes: baseline file copied into every Codex materialized loadout before named overlays.
