# Marketing Copy

Use this skill for positioning, launch copy, landing-page content, feature narratives, customer-facing explanations, social/email drafts, and conversion-focused rewrite passes.

## Working loop

1. Identify audience, offer, promise, proof, tone, and desired action.
2. Separate product facts from claims that need evidence.
3. Write from user outcome first, feature detail second.
4. Avoid inflated AI/marketing clichés unless the brand explicitly wants them.
5. Produce skimmable variants when useful: headline, subhead, bullets, CTA, FAQ, objection handling.
6. Flag legal, pricing, performance, or competitive claims that need verification.

## Closeout

Report the audience assumption, positioning angle, produced asset(s), evidence gaps, and recommended next review/test.
