# Tutorials

Step-by-step walkthroughs that take you from zero to a working result. Each tutorial favors concrete commands and expected outputs over abstract theory.

## Shipped

- [Your first loadout run](first-loadout-run.md) — validate the repo, resolve an explicit loadout, materialize a Claude sandbox output, and inspect the generated manifest. About five minutes.
- [Prepare Claude and Codex from one loadout](prepare-claude-and-codex.md) — materialize both runtime surfaces and compare parity. About ten minutes.
- [Add a new loadout](add-a-new-loadout.md) — create a small specialty loadout, validate it, and prove inheritance in sandbox output. About ten minutes.
- [Onboard a system into agents](onboard-a-system-into-agents.md) — review source behavior, generate Claude/Codex sandboxes, and stop at approval. About ten minutes.
