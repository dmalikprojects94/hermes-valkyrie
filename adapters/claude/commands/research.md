# /research

## Purpose

Run an investigation-first pass and summarize only evidence-backed findings.

## Procedure

1. Gather repo/docs/runtime evidence before reaching conclusions.
2. Separate confirmed facts from assumptions.
3. Name the exact files, commands, or docs that support the conclusion.

## Required output shape

- **Question**
- **Findings**
- **Evidence**
- **Unknowns**
- **Recommendation**

## Final reporting

After the command-specific output, end the run with the standard final report headings from `rules/10-reporting-format.md` unless the operator asked for a different deliverable shape.

- Notes: exposes shared default behavior as Claude slash-command workflow surface.
