# /prompt-optimize

## Purpose

Tighten a loose operator request before execution starts.

## Procedure

1. Follow the prompt-prep pipeline in `rules/20-prompt-prep-pipeline.md`.
2. Do not begin implementation.
3. Return the tightened prompt in copy-ready form.

## Required output shape

- **Restated**
- **Assumptions**
- **Out of Scope**
- **Deliverable**
- **Verification**
- **Tightened Prompt**

## Final reporting

After the command-specific output, end the run with the standard final report headings from `rules/10-reporting-format.md` unless the operator asked for a different deliverable shape.
