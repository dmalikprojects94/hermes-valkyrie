# /feature-dev

## Purpose

Implement a feature with explicit plan, execution, and verification discipline.

## Procedure

1. Confirm the deliverable and out-of-scope boundary.
2. Make changes in small steps.
3. Verify with tests or runtime checks before finalizing.

## Required output shape

- **Feature Goal**
- **Implementation Steps**
- **Verification**
- **Residual Risk**

## Final reporting

After the command-specific output, end the run with the standard final report headings from `rules/10-reporting-format.md` unless the operator asked for a different deliverable shape.
